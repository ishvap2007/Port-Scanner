# Python Port Scanner

A simple TCP Port Scanner built using Python sockets.

## Features

- Scan ports 1-1024
- Accepts IP address or domain name
- Displays open ports
- Beginner-friendly project
- Uses Python socket library

## Requirements

Python 3.x

## Run

```bash
python port_scanner.py
```

Example

```
Enter Target IP or Domain:
scanme.nmap.org

Port 22 is OPEN
Port 80 is OPEN
```

## Educational Purpose

This project is intended for educational and ethical security testing only.
